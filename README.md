# Retail Sales and Profitability Analysis Dashboard (2014–2017)

## Project Overview
This project analyzes retail sales and profitability data from 2014 to 2017 using an interactive dashboard. It provides insights into sales performance, profit margins, regional sales, product categories, and discount distribution.

## Key Performance Indicators
- Total Sales: $2.30M
- Total Profit: $286.4K
- Unique Orders: 5,009
- Profit Margin: 12.47%

## Dashboard Features
- Sales and profit analysis by product category
- Regional sales comparison
- Profit analysis by region
- Sub-category discount analysis
- Interactive filters and slicers
- KPI visualization for business performance monitoring

## Tools and Technologies
Add the tools you actually used to create this dashboard, such as Microsoft Excel, PivotTables, PivotCharts, and slicers.

## Project Objectives
- Analyze retail business performance
- Identify profitable product categories
- Compare sales across regions
- Understand discount distribution across sub-categories
- Present business insights through data visualization
